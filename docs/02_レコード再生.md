# レコード再生・回転操作

## 回転対象

`#record`は`role="slider"`を持つキーボード操作可能な要素です。

レコードへのポインター操作開始時に、モバイルブラウザの自動再生制限を満たす形で選択中の音声を再生します。音声は停止位置を保持し、次回の回転開始時に続きから再生します。音声はループし、右回転では先頭、左回転では末尾へ循環します。

| 属性 | 値 |
| --- | --- |
| `tabindex` | `0` |
| `aria-label` | `レコードを回す` |
| `aria-valuemin` | `0` |
| `aria-valuemax` | `360` |
| `aria-valuenow` | 現在角度の0〜359度 |

## ポインター操作

1. レコード上でポインターを押下すると操作を開始します。
2. レコード中心から見たポインター角度の差分で回転角度を更新します。
3. 押下中は`NOW SPINNING`へ変わり、ドラッグ案内を隠します。
4. ポインターを離すと、操作速度に応じた慣性回転を開始します。
5. 慣性は毎フレーム速度を`0.965`倍し、速度が十分小さくなると停止します。
6. 回転停止後は`READY TO SPIN`へ戻ります。

音声の`playbackRate`は回転速度の絶対値を`0.5〜2倍`に収め、急激な音切れを防ぐため滑らかに追従させます。右回転時は通常再生、左回転時はWeb Audioで生成した逆順バッファを使って逆再生します。回転方向を切り替えても再生位置を引き継ぎます。

プレーヤーフッターには、音声の現在位置と総時間を`mm:ss / mm:ss`（1時間以上は`hh:mm:ss`）で表示し、現在の再生速度を`0.00x`形式で表示します。

## モバイル音声処理

- `AudioContext`生成時に、デフォルトコンテキストから取得したハードウェアサンプリングレートを明示します。取得できない場合は`48000Hz`を使用します。
- 初回のユーザー操作で、10msの無音バッファを再生してオーディオ出力をアンロックします。
- 音声ファイルは`fetch`で取得し、`decodeAudioData`でデコードした`AudioBuffer`を再生します。
- 通常再生と逆再生の両方をWeb Audioの`AudioBufferSourceNode`で処理します。
- `AudioBufferSourceNode.loop`を有効にし、回転方向に応じて再生位置を循環させます。

角度表示は正規化した3桁表記（例：`000°`、`045°`）です。速度メーターは操作速度に応じて0〜100%で表示します。

## キーボード操作

レコードにフォーカスした状態で次のキーを使用できます。

| キー | 動作 |
| --- | --- |
| `ArrowRight` | 12度回転し、右方向の慣性回転を開始 |
| `ArrowLeft` | 12度回転し、左方向の慣性回転を開始 |

## リセット

ヘッダーのリセットボタンを押すと、次を実行します。

- 慣性回転を停止
- 回転角度を0度に設定
- 角度表示を`000°`に設定
- `aria-valuenow`を`0`に設定
- 再生状態を`READY TO SPIN`に設定
- `DRAG THE VINYL`を再表示

## 表示値の更新

レコード変更時には、ラベル番号、セッション番号、アルバム番号、アーティスト名、タイトル、アクセントカラー、音声バッファを選択レコードに同期します。
