# レコード再生・回転操作

## 初回音声許可

初回表示時は`SplashController`がスプラッシュを表示し、`TAP TO START`以外のアプリ領域を操作できない状態にします。クリック時に`AudioContext`をアンロックし、スプラッシュを非表示にします。

スプラッシュ表示中も、レコード一覧、選択中レコードの音声、cookie状態の読み込みをバックグラウンドで実行します。音声ロードの完了はスプラッシュ解除の条件にしません。

## 回転対象

`#record`は`role="slider"`を持つキーボード操作可能な要素です。
レコード本体は固定し、回転アニメーションは内部の`#label`（`.label`）だけへ適用します。
`#label`と`PagePlayer`には選択中レコードの`imageUrl`を背景画像として表示し、ラベル内のテキストは表示しません。

| 属性 | 値 |
| --- | --- |
| `tabindex` | `0` |
| `aria-label` | `レコードを回す` |
| `aria-valuemin` | `0` |
| `aria-valuemax` | `360` |
| `aria-valuenow` | 現在角度の0〜359度 |

## ポインター操作

1. レコード上でポインターを押下すると再生を開始します。
2. レコード中心から見たポインター角度の差分で回転角度を更新します。
3. 押下中は`NOW SPINNING`へ変わります。
4. ポインターを離すと、操作速度に応じた慣性回転へ移行します。十分な速度がある場合、慣性回転は速度を維持して継続します。
5. 慣性回転中は速度に応じて再生速度と回転メーターを更新します。
6. 慣性開始しきい値を下回る速度で離すと回転と再生を停止し、`READY TO SPIN`へ戻ります。

プレーヤーステージの左右スワイプでは、右で次、左で前のレコードへ切り替えます。再生中の切り替えでは盤面の回転角度・速度・方向と慣性回転を維持し、新しい音源のロード後に再生を継続します。

右回転時は通常再生、左回転時はWeb Audioで生成した逆順バッファを使って逆再生します。回転方向を切り替えても再生位置を引き継ぎ、0秒地点から逆回転した場合は音声末尾へ循環して再生します。

## 再生速度と表示

回転速度の割合から`playbackRate`を算出し、再生速度を滑らかに追従させます。表示は`0.00x`形式です。

ヘッダーメニュー内の速度ボタンは次の操作に対応します。

- `playbackX1Button`：再生速度を1.0倍に設定
- `PlaybackSpeedReduction`：再生速度を0.1倍減算
- `PlaybackSpeedIncrement`：再生速度を0.1倍加算
- `playbackReverse`：再生方向を反転

速度は0〜2倍の範囲で制限されます。速度ボタンをクリックすると、設定速度が0倍以上の場合は音声再生を開始し、設定速度に応じて`record`の回転速度も同期します。速度ボタンで設定した値は、次の回転操作まで維持します。

プレーヤーフッターには次を表示します。

- `audioSeek`：音声ファイル上の再生秒数を指定するシークバー
- `audioTime`：現在秒数と総時間（`mm:ss / mm:ss`、1時間以上は`hh:mm:ss`）
- `playbackRateValue`：現在の再生速度
- `meterFill`：回転速度メーター
- `angleValue`：正規化した3桁の回転角度（例：`000°`）
- `playState`：`READY TO SPIN`、`NOW SPINNING`、ロード・エラー状態

## ノイズ音声

ヘッダーの`noiseButton`で、`assets/ogg/record_noise_loop.ogg`の同期再生をON/OFFします。

- 初期値はOFFです。
- ON時のみノイズ音声をロードします。
- メイン音声と同じ再生秒数、方向、速度、シーク位置で再生します。
- ノイズ音声は短いループとして再生します。
- `aria-pressed`と`is-active`でボタン状態を表現します。
- ON/OFF状態は`groove-record-noise-enabled` cookieへ保存し、再表示時に復元します。

## ビジュアライザー

メニューの`visualizerButton`でビジュアライザー描画をON/OFFします。初期値はONです。OFF時は描画ループを停止してキャンバスを消去します。選択画面表示中の一時非表示とは別に設定状態を管理し、`groove-record-visualizer-enabled` cookieへ保存して再表示時に復元します。

## 状態の保存

`PlaybackStateRepository`は次の状態をcookieへ保存します。

| 状態 | cookie | 保存タイミング |
| --- | --- | --- |
| 選択レコードID | `groove-record-index` | レコード選択時 |
| 再生秒数 | `groove-record-playback-seconds` | 再生中、シーク確定時、ページ離脱時 |
| ノイズ同期状態 | `groove-record-noise-enabled` | `noiseButton`切替時 |
| ビジュアライザー描画状態 | `groove-record-visualizer-enabled` | `visualizerButton`切替時 |

ページ再表示時は、cookieのレコードID、レコードに対応する再生秒数、ノイズ同期状態、ビジュアライザー描画状態を復元します。旧再生位置cookie`groove-record-playback-position`も読み込み対象です。

## 音声ロード

レコード変更時は、音声取得と`decodeAudioData`によるデコードが完了するまで`LOADING AUDIO`を表示します。再生開始後も、`AudioContext`の再開や再生ノードの開始が遅れている間は、実際に再生可能になるまで`LOADING AUDIO`を表示します。ロード完了後に再生可能となり、失敗時は`AUDIO LOAD ERROR`を表示します。

レコード音声は`assets/data/records.json`の`audioUrl`から取得します。`WebAudioEngine`は正転用・逆転用の`AudioBuffer`を生成し、選択中の音源だけをキャッシュします。音源を切り替えると前の音源バッファを解放対象にし、複数曲のデコード済みデータを蓄積しないようにします。ビジュアライザーには`AnalyserNode`の周波数データと時間領域波形データを毎フレーム渡します。

## モバイル音声処理

- `AudioContext`はブラウザー既定のデバイス対応サンプリングレートを使用します。
- `TAP TO START`のユーザー操作で`AudioContext`をアンロックします。
- 初回操作では10msの無音バッファも再生し、オーディオ出力を有効化します。
- 音声ファイルは`fetch`で取得し、`decodeAudioData`でデコードします。
- 通常再生と逆再生を`AudioBufferSourceNode`で処理します。
- メイン音声とノイズ音声の`AudioBufferSourceNode`を同じ出力解析ノードへ接続します。

## ブラウザジェスチャー制御

`BrowserInteractionController`（`src/presentation/browser-interaction-controller.js`）で次のブラウザージェスチャーを抑止します。

- 画面最上部からの下方向スワイプによるプルダウンリフレッシュ
- 左端から右方向、右端から左方向のエッジスワイプによる履歴移動

横方向のレコード選択スクロールは許可します。

## キーボード操作

レコードにフォーカスした状態で次のキーを使用できます。

| キー | 動作 |
| --- | --- |
| `ArrowRight` | 右方向へ回転し、慣性回転を開始 |
| `ArrowLeft` | 左方向へ回転し、慣性回転を開始 |
