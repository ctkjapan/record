# レコード選択

## レコード一覧

`assets/data/records.json`がレコード一覧の唯一の定義元です。`RecordJsonRepository`が読み込み、件数はJSONから動的に表示します。各項目の`title`は`Record`で` / `を区切りにアーティスト名と曲名へ分け、`color`は盤面のアクセント色、`audioUrl`は音声、`imageUrl`は`#label`と`PagePlayer`の背景画像に使います。ラベル内にテキストは表示しません。

一覧内容を変更するときはJSONを更新してください。画面の件数や表示名を別ファイルへ重複定義しません。

画面表示時は`groove-record-index` cookieに保存されたレコードを選択状態として、タイトル、アルバム番号、アーティスト名、アクセントカラー、背景画像、音声ファイルをプレーヤーへ反映します。保存値がない、または一覧外の場合は`001`を選択します。同じレコードの再生秒数が保存されている場合は、その秒数も復元します。

## 選択画面の表示切り替え

1. メニューの`Choose your vinyl.`を押すと、再生と慣性回転を継続します。
2. プレーヤーを表示したまま、選択パネルを上から重ねて表示します。
3. `body`に`picker-open`を付与してヘッダーを切り替えます。この画面切り替えでは`--accent-color`を変更せず、レコード選択後に選択レコードの色へ更新します。
4. 選択中レコードを中央へスクロールします。

プレーヤーステージの`record`以外で方向別のスワイプ操作を行えます。`record`上のスワイプはレコード回転操作として扱います。

ステージを下へスワイプするとこの画面を開きます。左右スワイプは画面を開かず、右で次、左で前のレコードを選択します。先頭・末尾では反対端へ循環します。選択中カードの`is-selected`とフォーカス中カードの`is-focused`、位置表示も新しいレコードへ同期します。

`changeButton`は選択画面で`aria-pressed="true"`になります。ボタンの表示テキストは変わりません。

## カード操作

- レコードカードは横一列に配置します。
- カードには`record.title`を` / `で分け、アーティスト名と曲名を別の行に表示します。
- タッチ操作では左右スワイプで一覧をスクロールできます。
- マウス操作では左ボタンのドラッグで一覧をスクロールできます。
- 1番目のレコードにフォーカス中、左端から右へスワイプすると通常の横スクロールより優先して最後のレコードへ循環します。最後のレコードから左端へのスワイプも同様に優先して1番目へ循環します。
- スクロール停止時に中央へ最も近いカードをフォーカス対象にします。
- 中央以外のカードをクリックすると、そのカードを中央へスムーズに移動します。
- 中央のレコード円盤をクリックするとレコードを選択し、プレーヤー画面へ戻ります。
- マウス移動なしで中央カードを`pointerup`するとレコードを選択し、プレーヤー画面へ戻ります。
- ドラッグ直後のクリックは選択操作として扱いません。

カードの状態は次のクラスで表します。

- `is-focused`：中央表示中のカード。拡大・高い不透明度で表示
- `is-selected`：現在選択中のカード。強調リングを表示

## 選択後の状態

選択したレコードのタイトルを`再生中`メッセージに表示し、背景画像を`#label`へ反映してプレーヤーへ戻ります。選択レコードの色は`--accent-color`とビジュアライザーへ反映します。

カードからレコードを選択した場合、レコードを変更すると現在の再生と慣性回転を停止し、回転角度を0度へ戻します。プレーヤーステージの左右スワイプで変更した場合は回転角度・回転速度・方向・慣性状態を維持し、再生中なら新しい音源のロード後に同じ状態で再生を続けます。変更後の音源は0秒から再生します。

選択状態を`groove-record-index` cookieへ保存し、選択中レコードの音声URLを`WebAudioEngine`へ渡します。音声はロード完了後に再生可能になります。
