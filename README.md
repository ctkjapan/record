
スマホ対応で
レコード（円盤）をスワイプして回せるwebページをつくって

レコードを変更できる機能を追加してください。
変更ボタンを押すとUIが切り替わり、
レコードが横に並びに配置され左右スワイプでレコードの選択切り替え
レコードの真ん中をクリックでそのレコードに変更します。

レコードを変更のレコードの形を円盤にしてください。

レコードの選択切り替えのスワイプはマウス操作でもできるようにしてください。
レコードの真ん中をクリックでそのレコードに変更した時点で元の画面に戻るようにしてください。

UIとデザインを <https://tympanus.net/Development/RecordPlayer/> のようにしてください

回転速度の50%が再生速度1倍とし、
回転速度0%が再生速度の最小
回転速度100%再生速度の最大となるように調整してください。

const MIN_PLAYBACK_RATE = 0;
const MAX_PLAYBACK_RATE = 4;

画面表示時に１つめのレコードの情報や色が反映するようにしてください。

レコード選択後にmp3を完全にロードしてから再生可能になるようにしてください。
ロード中なのかがわかるように画面表示じてください。
